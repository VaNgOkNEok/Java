📌 Инструкция по запуску утилиты DataFilter (https://github.com/VaNgOkNEok/Java/tree/JAVA/util/src)
-------------------------------------------------------------------------------------------------------
📜 Описание

Программа DataFilter предназначена для фильтрации данных:

Целые числа → integers.txt
Дробные числа → floats.txt
Строки → strings.txt

Дополнительно программа позволяет:
✔️ Добавлять префиксы в названия выходных файлов
✔️ Указывать путь для сохранения файлов
✔️ Включать вывод статистики о записанных данных

Файлы для записи создаются по мере необходимости.
-------------------------------------------------------------------------------------------------------
🔧 Требования

Версия Java
  -Программа разработана и протестирована на Java 17.
  -Также должна работать на Java 11+, но рекомендуется использовать Java 17.
Система сборки
  -Не использовалась.
-------------------------------------------------------------------------------------------------------
⚙️ Инструкция по применению

Аргументы командной строки
Аргумент	Описание
-o <директория>	Указывает папку для сохранения выходных файлов
-p <префикс>	Добавляет префикс к именам выходных файлов
-a	Добавляет данные в существующие файлы вместо перезаписи
-s	Включает краткую статистику (количество элементов, записанных в файлы)
-f	Включает полную статистику (для чисел: количество, минимум, максимум, сумма, среднее; для строк: количество, длина самой короткой и самой длинной строк)
<файлы>	Список входных файлов
-------------------------------------------------------------------------------------------------------
📌 Примеры запуска

-Простой запуск:
>java X:\JAVA\util\src\Main.java X:\JAVA\in1.txt X:\JAVA\in2.txt
-Вывод в указанную директорию:
>java X:\JAVA\util\src\Main.java -o output/ X:\JAVA\in1.txt X:\JAVA\in2.txt
-Добавление данных в существующие файлы с префиксом:
>java X:\JAVA\util\src\Main.java -o output/ -a -p filtered_ X:\JAVA\in1.txt X:\JAVA\in2.txt
-Полная статистика:
>java X:\JAVA\util\src\Main.java -o output/ -a -f -p filtered_ X:\JAVA\in1.txt X:\JAVA\in2.txt
-------------------------------------------------------------------------------------------------------
📌 Обработка ошибок:

🚨 Некорректные аргументы
  -При вводе несуществующего аргумента (например, -h) программа выводит предупреждение "Warning: Unrecognized character: -h" и продолжает работу.
🚨 Отсутствие пути при использовании -o
  -Программа создаёт файлы в текущей директории.
🚨 Отсутствие префикса при использовании -p
  -Файлы создаются со стандартными именами.
🚨 Использование запрещённых символов в пути (-o)
  -Если путь содержит зарезервированные символы (<, >, :, /, \, |, ?, *, "), программа создаёт файлы со стандартными именами.
